# product-card
Изображение продукта (320x320px)
Бейдж "NEW" в верхнем левом углу
Название товара
Рейтинг (звездочки + текст "4.5 (120 отзывов)")
Цена с перечеркнутой старой ценой
Кнопка "Добавить в корзину"
Иконка "избранное" (сердечко) в правом верхнем углу

Технические требования:

Чистый HTML + CSS (без фреймворков)
Адаптивность: Desktop (1200px), Tablet (768px), Mobile (375px)
Hover эффекты на кнопке и иконке избранного
Семантическая верстка
БЭМ методология для именования классов
Использование CSS Grid или Flexbox
Поддержка браузеров: Chrome,
Firefox, Safari (последние 2 версии)

Интерактивность (опционально, +баллы):

При клике на "избранное" - иконка заполняется цветом
Анимация появления карточки при загрузке страницы
Увеличение изображения при наведении

[Смотреть демо](https://bgocean.github.io/product-card/)
